# 🎨 РОЗРОБКА ПРОГРАМИ ОБЛІКУ УЧАСНИКІВ АРТ-ПРОСТОРУ

---

## 📖 Опис проєкту

Даний проєкт являє собою консольний застосунок, розроблений мовою **C++**, призначений для автоматизації обліку учасників арт-простору.

Програма забезпечує зручне зберігання, пошук, редагування та видалення інформації про учасників, а також формування статистичних звітів із використанням файлового зберігання даних.

---

## 🎯 Мета проєкту

Створення програмного забезпечення для автоматизації процесів обліку учасників арт-простору з використанням сучасних засобів програмування мовою **C++**.

---

## ⚙️ Основні можливості

### ➕ Робота з учасниками

* Додавання нового учасника
* Перегляд повного списку учасників
* Пошук за прізвищем
* Пошук за електронною поштою
* Редагування інформації
* Видалення записів

### 📊 Аналітика та звітність

* Підрахунок загальної кількості учасників
* Формування статистичних звітів
* Аналіз типів участі

### 💾 Зберігання даних

* Автоматичне збереження у файл
* Завантаження даних при запуску програми
* Простий текстовий формат зберігання

## 🚀 Інструкція із запуску

### Варіант 1. Visual Studio

1. Відкрити файл `Art.sln`.
2. Обрати конфігурацію **Debug** або **Release**.
3. Натиснути:

```text
F5
```

для запуску з налагодженням або

```text
Ctrl + F5
```

для запуску без налагодження.

---

### Варіант 2. Запуск готового виконуваного файлу

Після успішної збірки проєкту перейти до папки:

```text
x64/Debug/
```

та запустити:

```text
Art.exe
```
